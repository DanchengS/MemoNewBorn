# 新生儿及孕产期物品清单

## 大件要买
- **Stroller**
  - **Uppababy Vista**：我们买的这个，最多可以装俩坐着的小孩。缺点是重，但高景观、稳、底下能装超多东西。
  - **Cybex**：挺好看，也不错。
  - **Graco**：老美比较常用。

- **提篮 Infant Car Seat**
  - 必须要有才能出院，把小孩儿装篮子里，再把篮子装汽车/推车上。
  - 建议买和 Stroller 同品牌的 car seat 比较方便。不同品牌需要买 adapter。
  - Infant car seat 一般坐 4 个月左右就淘汰。注意 **有效期**（通常约 10 年），买二手要注意。

- **成长椅**
  - **Stokke**：基本人手一个。
    - 小时用 newborn set（又名拉屎神器），让娃躺上面。
    - 长大可以当椅子用。
    - 国内可以买 **Stokke 轮子**（官方没有），椅子能在家里推来推去，方便。

## Bedding
- **Mattress**
  - **Natruepedic（我们用的）**
    - 配 breathable 床垫套，防窒息
    - 纯 Organic，本身防水
  - **Newton**：也很多人推荐，breathable
- **床架**：无所谓，可买 convertible 用到几岁，也可以 Ikea。优先考虑无油漆（避免啃）。
- **Bassinet → Crib**：
  - 小月龄时用 bassinet，靠床一侧
  - 大了换 crib（儿医建议：同房不同床）
- **床品**：
  - 淘宝/1688 买床套、bassinet 床垫套（纯棉）

## 海淘推荐
- **口水巾**：6 层纱布以上才够软。备 20–30 条，勤换预防口水疹。
- **拍嗝巾**：竖抱拍嗝防吐奶，或趴睡垫肩。
- **隔尿垫**
- **方巾**：不同大小，10 多条，擦脸、洗澡都能用。
- **床套**
- **包巾**：小月龄睡觉必备，本地质量不佳，建议海淘。
- **睡袋**：可准备几条，本地质量好但贵；孩子长得快，淘汰快。
- **和尚服连体衣**：避免套头，推荐 **乖奇熊**，质量好。
- **婴儿游泳桶**：放电、缓解二月胀气。
- **袜子/手套**：防抓脸。新生儿可用袜子当手套，长大就是袜子了。
- **水龙头外接花洒** 在厕所洗手盆给娃洗屁股方便很多很多

## 产后月子药膳
- [Newspring 月子药膳](http://www.newspring.tw/Products/Product/154179)

## 新生儿必备
- **身体乳**（保湿，防干燥）
  - CeraVe Baby Moisturizing Lotion
  - Cetaphil 大白罐
- **红屁股护理**
  - 日常：Destin Daily Defense Cream
  - 严重：Destin Maximum Strength
  - 建议流程：拉屎 → 水洗 → 棉柔巾擦干 → 抹药膏 → 换尿布
- **凡士林**：日常替代 Daily Defense，透气。
- **Tubby Todd**：贵，但新生儿起疹子好用。
- **Costco 狗尿垫**：换尿布/外出必备，便宜实用。
- **包巾/睡袋**
  - 小月龄：SwaddleMe 包巾
  - 大点：Love To Dream
- **衣物**
  - Gerber 好用
  - 开衫比套头好穿
- **洗澡盆**
  - amazon有卖
